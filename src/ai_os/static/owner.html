How to read this screen

  • Queued: task saved; a worker has not claimed it yet.
  • Running: worker claimed the task; agent steps show actual persisted activity.
  • Completed: final output is saved and visible above.
  • Failed / blocked: inspect the error; blocked work requires owner review before retry.

Worker status comes from persisted heartbeats. Active means the process is reporting to the shared database; it does not prove the model provider is responding.
